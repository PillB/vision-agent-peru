# Dataset and fixture cards

## User-provided authorized video

- Collection: selected locally by the operator; no automatic network ingestion.
- Consent/authority: the UI requires the operator to approve local hashing and analysis.
- Processing: browser decode, adaptive samples, detections, tracks, crops, optional embeddings.
- Retention: best-effort 24-hour startup purge for normal IndexedDB evidence stores; explicit delete is available.
- Export: only after a visible user action; external transmission is not configured.
- Limitations: source coverage, timestamps, camera labels, skipped intervals, decoding failures, occlusion, compression, sampling, and model error.

## Repository demonstration media

Images and videos under `public/sim` are deterministic demonstration fixtures. Records generated by “Load labeled simulation evidence” carry `useCaseId: explicit-labeled-simulation`, `modelId: deterministic-simulation`, and `revision: fixture-v1`. They are never presented as model accuracy evidence.

## Missing evaluation dataset

No consented held-out Peruvian surveillance benchmark with ground-truth objects, tracks, retrieval relevance, open-set negatives, and subgroup documentation is committed. Therefore precision, recall, false-positive reduction, FPS, identity, fairness, and “calibrated” fusion claims remain prohibited.
